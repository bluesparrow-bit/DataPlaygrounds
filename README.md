# 🌟 Data Engineering Learning Journey

Hi there! I'm **Mohammad Maher**, a Data Engineering student at the Digital Egypt Pioneers Initiative (DEPI) and a data analyst intern at HVIA Data & AI Solutions. I'm a passionate learner on a mission to gain hands-on experience, grow toward Data Science, and share what I learn along the way.

This repository is my personal workspace: course labs, practice projects, experiments, and real tasks from my internship. It covers **SQL, Python, data wrangling, data analysis, MongoDB, Airflow, data warehousing, Hadoop, Hive, PySpark, and data pipelines**.

## 📁 Folder Details

### [0-Cheatsheets](0-Cheatsheets)
Quick reference guides organized by topic:
- **Fedora Documentaions/** – dual-boot troubleshooting, NVIDIA driver setup, SSH/SCP guides, battery management
- **PyLibs/** – cheat sheets for pandas, NumPy, Matplotlib, BeautifulSoup, Selenium, PySpark RDDs
- **SQL+NoSQL/** – SQL and NoSQL cheat sheets, SQL execution order diagram
- **Terminals/** – Bash, Git, Hadoop, PowerShell, and Docker command references
- `Base-R-Cheat-Sheet.pdf` – R language quick reference

### [Baraa_SQL](Baraa_SQL)
Hands-on applications and notes from Baraa's SQL courses, along with the course content.

### [Data_Wrangling](Data_Wrangling)
Python notebooks for practicing data cleaning and exploration.
- `data/` – datasets used by the notebooks
- `memos/` – notes and write-ups
- `airbnb-new-york-city.ipynb` – cleaning and exploring the NYC Airbnb dataset
- `penguins.ipynb` – wrangling the Palmer Penguins dataset

### [DEPI](DEPI): Digital Egypt Pioneers Initiative
Assignments and labs from the DEPI Data Engineering track, organized in the order I studied them:

| # | Folder | What's inside |
|---|--------|---------------|
| 0 | [0-Data-Pipline-Example](DEPI/0-Data-Pipline-Example) | An end-to-end data pipeline example |

| 2 | [2-SQL-Laps](DEPI/2-SQL-Laps) | Data manipulation with SQL and advanced SQL |
| 3 | [3-MongoDB](DEPI/3-MongoDB) | MongoDB assignments and labs |

### [GCI_World](GCI_World)
Homework and lecture notebooks from [GCI World](https://weblab.t.u-tokyo.ac.jp/en/lecture/gci/), a free, 3-month online AI and data science training program organized by the Matsuo-Iwasawa Laboratory at the University of Tokyo, with support from JICA.
- [HW](GCI_World/HW) – homework notebooks, one per session (HW1 for Session 2 through HW5 for Session 6)
- [Lec-Notebooks](GCI_World/Lec-Notebooks) – lecture notebooks for lectures 2 to 6
- [Lec-Notebooks-Answerd](GCI_World/Lec-Notebooks-Answerd) – answered versions of lecture notebooks (lectures 2 – 6)

### [HVIA](HVIA): Internship at [HVIA Data & AI Solutions](https://www.linkedin.com/company/hvia/posts/)
HVIA is a data and AI solutions start-up. I interned there as a **data analyst**, working on real-world analysis tasks. This folder contains the tasks, datasets, and my solutions from that period.
- [Task-0](HVIA/Task-0) – Olist e-commerce dataset analysis

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/bluesparrow-bit/DataPlaygrounds.git
cd DataPlaygrounds

# 2. (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Launch Jupyter to explore the notebooks
jupyter notebook
```
